Bienvenue dans Lexora — le jeu de mots qui parle votre langue

Catégorie : Découverte 6 septembre 2026 Lecture : 3 min

Lexora est un jeu de mots du type « trouver le mot en 6 essais ». Mais avec une particularité : il se joue dans quatre langues — le français, l'anglais, le fon et le russe.

Une règle universelle

Le principe tient en une phrase : chaque jour, un mot mystère de 5 lettres est proposé, et vous avez six essais pour le trouver. À chaque proposition, les cases changent de couleur : verte si la lettre est à la bonne place, jaune si elle est dans le mot mais ailleurs, grise si elle n'y est pas. Simple à apprendre, difficile à dompter.

Quatre dictionnaires, une interface multilingue

La différence de Lexora, c'est son choix éditorial. Plutôt qu'un seul dictionnaire, le jeu embarque le français, l'anglais, le fon (fɔngbè) et le russe. Vous changez de dictionnaire en un geste dans les réglages — et l'interface elle-même peut s'afficher dans chacune de ces langues.

Deux modes de jeu

Le mode Quotidien propose un mot partagé par tous les joueurs chaque jour, idéal pour comparer vos résultats. Le mode Niveaux vous fait progresser à travers des mots choisis et de plus en plus exigeants.

Commencer en 30 secondes

Vous pouvez jouer immédiatement dans votre navigateur, sans compte et sans installation. À l'écran, un bouton permet d'installer Lexora comme application afin de jouer hors-ligne. Sur Android, une version APK arm64 est aussi disponible dans la section Télécharger.

Bonne partie ! Et si un mot vous manque, dites-le-nous : nous enrichissons les dictionnaires à chaque mise à jour.
