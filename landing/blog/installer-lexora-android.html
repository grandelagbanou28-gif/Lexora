Installer Lexora sur Android : PWA ou APK arm64 ?

Catégorie : Guide 6 septembre 2026 Lecture : 3 min

Deux façons principales d'installer Lexora sur Android : la PWA, en un geste depuis Chrome, ou l'APK officiel arm64. Voici comment choisir.

Option 1 — la PWA (recommandée pour débuter)

Une PWA (application web progressive) s'installe comme une application native, mais c'est votre navigateur qui fait tout le travail.

  1. Ouvrez Lexora dans Chrome.
  2. Appuyez sur le menu ⋮ en haut à droite.
  3. Choisissez Ajouter à l'écran d'accueil, puis Installer.

Résultat : une icône Lexora sur votre écran d'accueil, un lancement en plein écran, et le jeu qui fonctionne hors-ligne. Aucun fichier à télécharger, aucune permission demandée.

Option 2 — l'APK arm64 (l'application « classique »)

Pour celles et ceux qui préfèrent une vraie application fichier à installer, Lexora publie un APK arm64 (arm64-v8a), c'est-à-dire optimisé pour les téléphones 64 bits — la quasi-totalité des Android modernes.

  1. Téléchargez l'APK arm64 depuis notre dépôt GitHub officiel.
  2. Ouvrez le fichier .apk téléchargé.
  3. Autorisez l'installation depuis « sources inconnues » si Android le demande, puis confirmez.

Le build est généré automatiquement à chaque mise à jour du code source : vous êtes sûr d'avoir la dernière version.

Quoi choisir ?

  • PWA : zéro fichier, installation en 10 secondes, mise à jour automatique, hors-ligne complet. Idéale pour la plupart des gens.
  • APK : une application « installée » au sens classique, utile si vous voulez conserver le fichier, la partager sur un appareil sans store, ou l'utiliser hors du navigateur.

Les deux versions sont gratuites, sans publicité et sans compte. Vous trouverez tout le détail dans la page Télécharger. Bon jeu !
