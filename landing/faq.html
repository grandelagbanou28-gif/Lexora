Questions fréquentes

Tout ce qu'il faut savoir pour installer, jouer et profiter de Lexora.

Comment joue-t-on à Lexora ?

Le but est de deviner le mot mystère en 6 essais maximum. Chaque essai doit être un mot valide de 5 lettres du dictionnaire choisi. Après chaque essai, la couleur des cases indique si la lettre est bien placée (verte), dans le mot mais mal placée (jaune) ou absente (grise).

Dans quelles langues puis-je jouer ?

Lexora propose quatre dictionnaires : le français, l'anglais, le fon (fɔngbè) et le russe. L'interface de l'application est elle aussi traduite dans ces quatre langues — le choix de la langue de l'app et du dictionnaire se fait dans les réglages.

Comment installer Lexora sur iPhone ou iPad (Safari) ?

Ouvrez Lexora dans Safari, puis appuyez sur le bouton Partager, choisissez Sur l'écran d'accueil, puis Ajouter. Lexora apparaîtra sur votre écran d'accueil comme une application native.

Comment installer Lexora sur Android (PWA) ?

Ouvrez Lexora dans Chrome, appuyez sur le menu ⋮, puis Ajouter à l'écran d'accueil et confirmez avec Installer. Le jeu se lance ensuite en plein écran, même hors-ligne.

C'est quoi l'APK arm64 ?

C'est le fichier d'installation Android officiel de Lexora, optimisé pour les téléphones 64 bits (arm64-v8a, la grande majorité des appareils modernes). Il est construit automatiquement à partir du code source et publié sur notre dépôt GitHub. Vous devrez autoriser l'installation d'applications depuis « sources inconnues » lors de l'installation.

Lexora fonctionne-t-il hors-ligne ?

Oui. Une fois installée (PWA ou APK), l'application et ses dictionnaires vivent sur votre appareil. Vous pouvez jouer sans réseau, partout.

Mes résultats sont-ils sauvegardés ?

Oui : vos parties, séries et statistiques sont enregistrées localement sur votre appareil et conservées d'une session à l'autre. Elles ne quittent jamais votre téléphone.

Un mot du dictionnaire est absent ou mal défini. Que faire ?

Écrivez-nous via la page Contact ou ouvrez une issue GitHub en indiquant le mot et la langue. Nous l'ajoutons ou le corrigeons lors d'une prochaine mise à jour — merci pour la contribution !

Lexora est-il gratuit ?

Oui, Lexora est entièrement gratuit, sans publicité et sans compte obligatoire. Son code source est public sur GitHub.
