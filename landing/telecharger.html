iPhone, Android ou ordinateur — installation PWA

Pas d'APK, pas de magasin d'applications : le navigateur installe Lexora sur votre écran d'accueil, comme une application native. 100 % sûr, 100 % hors-ligne.

Sur iPhone / iPad (Safari)

  1. Ouvrez le jeu dans Safari, puis appuyez sur le bouton Partager.
  2. Choisissez Sur l'écran d'accueil.
  3. Appuyez sur Ajouter en haut à droite. C'est tout !

Sur Android (Chrome)

  1. Ouvrez le jeu dans Chrome.
  2. Appuyez sur le menu ⋮, puis Ajouter à l'écran d'accueil.
  3. Confirmez avec Installer.

Sur ordinateur

  1. Ouvrez le jeu, puis cliquez sur l'icône Installer dans la barre d'adresse.
  2. Cliquez sur Installer.
