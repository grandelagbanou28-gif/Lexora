PWA — installation en un geste

Pas d'APK, pas de magasin d'applications : le navigateur installe Lexora sur votre écran d'accueil, comme une application native. 100 % sûr, 100 % hors-ligne, mise à jour automatique.

Sur iPhone / iPad (Safari)

Ouvrez le jeu dans Safari → Partager → Sur l'écran d'accueil → Ajouter.

Sur Android (Chrome)

Ouvrez le jeu dans Chrome → menu ⋮ → Ajouter à l'écran d'accueil → Installer.

Sur ordinateur

Ouvrez le jeu → icône Installer dans la barre d'adresse → Installer.
